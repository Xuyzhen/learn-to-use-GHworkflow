# learn-to-use-GHworkflow

## 流水线流程图

```
┌─────────────────────────────────────────────────┐
│                    e2e                           │
│                                                  │
│  ┌──────────┐            ┌──────────────────┐   │
│  │  build   │──output──→ │ failure analyze   │   │
│  │          │            │                  │   │
│  │ artifact │            │ 接收e2e output   │   │
│  │ ↑        │            │ 上传自身artifact │   │
│  └──────────┘            └──────────────────┘   │
│                                                  │
└──────────┬──────────────────────────┬───────────┘
           │ artifact                 │ workflow_run
           │ workflow_run             │
           ▼                          ▼
   ┌──────────────┐          ┌──────────────┐
   │  read e2e    │          │  upload obs  │
   │              │          │              │
   │ 下载e2e的   │          │ 下载failure  │
   │ artifact     │          │ analyze的    │
   │              │          │ artifact     │
   │ 追加自身     │          │              │
   │ 时间戳+秘钥  │          │ 追加自身     │
   └──────────────┘          │ 时间戳+秘钥  │
                             └──────────────┘

触发条件：e2e success → 下游全部执行
          e2e 失败/取消 → 下游全部跳过
```
